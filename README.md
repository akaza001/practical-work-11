Задача №1
Руководству пришла в голову идея сделать балльно-рейтинговую систему еще круче, поэтому каждый кабинет в университете был разделен на N строк и M столбцов, где вход в аудиторию располагается в верхнем левом (если смотреть на карту) углу, а преподаватель сидит в правом нижнем.
По заданной карте и количеству баллов в клетках (если в клетке положительное число, то это количество баллов прибавляется к сумме баллов студента, если отрицательное - вычитается) необходимо рассчитать маршрут, обеспечивающий максимальную сумму накопленных баллов при условии, что можно двигаться только вниз и вправо (только в соседние клетки, не по диагонали).
Например, если заданы значения:
2 -3 2 3
10 2 2 2
-3 20 2 2
Ответ должен быть в координатах ячеек:
0 0 (старт, обязательная точка)
1 0
1 1
2 1
2 2
2 3 (правый нижний угол, обязательная точка финала).
Задача №2
Арсен Маркарян — большой любитель свежих пирожков. У него есть N пирожков, каждый из которых имеет свою калорийность. Арсен решил, что ему нужно оптимально распределить свои пирожки по дням, чтобы не переедать, но при этом наслаждаться каждым днем.
Арсен хочет распределить пирожки по D дням так, чтобы:
1. В каждый день он ел хотя бы один пирожок.
2. Разница в калориях между самым калорийным и самым низкокалорийным пирожком в каждый день была минимальной.
Помогите Арсену определить минимальную возможную разницу в калориях между самым калорийным и самым низкокалорийным пирожком в любой из дней.
Входные данные:
Первое число N (1 ≤ N ≤ 1000) — количество пирожков.
Второе число D (1 ≤ D ≤ N) — количество дней.
Массив из N целых чисел, представляющих калорийность каждого пирожка.
Выходные данные:
Минимальная возможная разница в калориях для распределения пирожков по дням.

Задача №1
P.Diddy заблудился в лабиринте и хочет выбраться на улицу. Однако он, как известно, большой фанат pdf-файлов и не может пройти мимо ни одного такого! В лабиринте есть отметки о таких файлах, и P.Diddy должен собрать их как можно больше.
Входные данные:
Размеры лабиринта (N x M).
Лабиринт, где 0 — пустая клетка, 1 — стена, P — pdf-файл, E — выход.
Выходные данные:
Максимальное количество pdf-файлов, которое сможет собрать P.Diddy на пути к выходу.
